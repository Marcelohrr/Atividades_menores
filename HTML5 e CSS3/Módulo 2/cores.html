Formas de definir cores em CSS

Usando nomes de cores padrão em CSS

É fácil, mas o conjunto de cores é limitado.

Usando códigos hexadecimais ou valores RGB

As cores podem ser definidas por valores sequenciais de vermelho, verde e azul (e alpha, opcional, para transparência) que vão de 0 a 255, ou de 0 a FF (em hexadecimal), totalizando 16.777.216 combinações possíveis (4.294.967.296 com transparência). A sequência pode ser definida de duas maneiras:

  • #RRGGBB[AA] -> Pares de dígitos hexadecimais;
  • rgb[a](R, G, B[, A]) -> Sequência dos valores em decimal de rgb (de 0 a 255) e alpha (de 0 a 1).
* Alpha -> Representa a transparência da cor.

Usando valores HSL (Hue, Saturation, Lightness)

As cores também podem ser definidas por valores sequenciais de:

  • Matiz -> Representa a "cor pura" no círculo de cores, de 0° a 360°;
  • Saturação -> Intensidade da cor em percentual;
  • Luminosidade -> Brilho da cor em percentual;
  • Alpha -> Transparência de 0 a 1.

* Cada componente pode variar infinitamente dentro de seu intervalo (0–360, 0–100%, 0–100%, 0-1), com valores intermediários, como hsl(240.5, 73.2%, 50.7%, 0.2). Por isso, as possibilidades de combinação em HSL são infinitas.
