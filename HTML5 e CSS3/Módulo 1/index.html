Principais formatações, elementos semânticos e estruturais

Negrito

Negrito (<b>, de bold), apenas visual.

O mesmo destaque, porém com valor semântico (<strong>).

Itálico

Itálico (<i>), apenas visual.

A mesma ênfase, porém com valor semântico (<em>, de emphasis).

Marcação

Marcação (<mark>), com valor semântico.

Riscado

Riscado (<s>, de strike-through), apenas visual.

A mesma formatação, porém com valor semântico de texto deletado (<del>, de deleted).

Sublinhado

Sublinhado (<u>, de underline), apenas visual.

A mesma formatação, porém com valor semântico de texto inserido (<ins>, de inserted).

Texto sobrescrito e subscrito

Texto sobrescrito (<sup>, de superscript), apenas visual.

Texto subscrito (<sub>, de subscript), apenas visual.

Código-fonte e pré-formatação

Texto de código (<code>), com valor semântico.

A tag <pre> (preformatted) preserva espaços e quebras de linha:
n = int(input('Insira número:'))
    if n % 2 == 0:
        print('O número inserido é par.')
    else:
        print('O número inserido é ímpar.')

Links

A tag <a> (anchor) cria hiperlinks (ligações clicáveis que conectam uma página ou parte de um documento a outro recurso).

  • Âncora = destino do link
  • href (hypertext reference) = define o caminho do recurso
  • target = define onde o link será aberto
    • _self (padrão): mesma aba
    • _blank: nova aba
  • rel (relationship) = indica a relação entre o documento atual e o recurso vinculado
    • Segurança e privacidade
      • noopener: evita que a página referenciada acesse window.opener (previne tabnabbing, nos quais a página externa poderia redirecionar a aba original para um site falso)
      • noreferrer: também bloqueia window.opener e não envia o Referer HTTP ao link externo (impede que dados da URL original sejam expostos para o site externo)
    • Navegação e indexação (SEO)
      • dofollow (padrão): motor de busca pode seguir o link
      • nofollow: instrui motores de busca a não seguirem o link (não transfere autoridade ao site vinculado)
      • canonical: indica a URL canônica (a versão “oficial” ou principal) de uma página para SEO, quando existem URLs diferentes que mostram o mesmo conteúdo
    • Performance
      • preload: indica que o recurso deve ser carregado antecipadamente
      • prefetch: sugere que o navegador carregue o recurso para uso futuro
      • preconnect: estabelece conexão antecipada com um domínio externo
    • Estilo
      • stylesheet: define que o link é uma folha de estilo CSS
    • Navegação e estrutura de documentos
      • next / prev: indicam aos buscadores a relação entre páginas
      • alternate: versão alternativa do documento (ex: RSS, tradução)
    • Metadados e conteúdo
      • author: link para o autor do documento
      • license: indica a licença de uso do conteúdo
      • help: fornece documentação de ajuda
    • Informação
      • external: indica que o link leva para um site externo
      • friend: indica link de amizade ou rede social
      • tag: relaciona link a uma tag ou categoria
      • me: indica perfil próprio (WebID / OpenID)
