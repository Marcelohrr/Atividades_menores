Apenas estrutura

101. Faça um programa que tenha uma função chamada voto() que vai receber como parâmetro o ano de nascimento de uma pessoa, retornando um valor literal indicando se uma pessoa tem voto negado, opcional ou obrigatório nas eleições.

102. Faça um programa que tenha uma função chamada fatorial() que receba dois parâmetros: o primeiro que indique o número a calcular e o outro chamado mostre, que será um valor lógico (opcional) indicando se será mostrado ou não na tela o processo de cálculo do fatorial.

103. Faça um programa que tenha uma função chamada ficha(), que receba dois parâmetros opcionais: o nome de um jogador e quantos gols ele marcou. O programa deve mostrar a ficha, mesmo que algum dado não tenha sido informado.

104. Faça um programa que tenha a função leiaInt(), com funcionamento semelhante à função input(), só que fazendo a validação para aceitar apenas um valor numérico (erro personalizado se não for inserido um número inteiro).

105. Faça um programa que tenha uma função notas() que pode receber várias notas de alunos e retorne um dicionário com as seguintes informações referentes às notas: quantidade, a maior, a menor, a média da turma e a situação (que seja opcional). Adicione também as docstrings da função.

106. Crie um mini-sistema em JavaScript que consuma uma API dummy local para simular um manual de comandos. O usuário deverá digitar o nome de um comando no terminal e o programa deve buscar sua descrição em uma API local (JSON Server ou arquivo JSON servido localmente), exibindo o resultado na tela. O programa deve funcionar em loop, permitindo múltiplas consultas até que o usuário digite a palavra FIM, momento em que o sistema deve ser encerrado. O sistema deve tratar casos em que o comando não exista na base de dados, exibindo uma mensagem adequada. OBS.: utilize cores no terminal para diferenciar entrada do usuário, resultados e mensagens de erro.

107. Crie um módulo em JavaScript chamado moeda.js com as funções incorporadas aumentar(), diminuir(), dobro() e metade(). Faça também um programa que importe esse módulo e use algumas dessas funções.

108. Adapte o código do desafio 107, criando uma função adicional chamada moeda(), para mostrar os valores com formatação de valor monetário.

109. Modifique as funções que foram criadas no desafio 107 para que elas aceitem um parâmetro a mais, informando se o valor retornado por elas vai ser ou não formatado pela função moeda(), desenvolvida no desafio 108.

110. Adicione ao módulo moeda.js uma função chamada resumo(), que mostre na tela algumas informações geradas pelas funções que já temos no módulo criado até aqui.
